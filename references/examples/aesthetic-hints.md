# Aesthetic Skill — design-loop-hints Template

For skills that **provide design guidelines** (ui-ux-pro-max, designing-websites, etc.)

## How to use

Copy the `## design-loop-hints` section below into your SKILL.md. Focus on what your skill considers excellent for each criterion.

## Template

```markdown
## design-loop-hints

scoring-enrichment:
composition: "Layouts should follow the rule of thirds with intentional negative space"
typography: "Font pairings should create contrast — serif display + sans-serif body minimum"
color: "Palettes should use no more than 3 hues with tonal variations for depth"
identity: "The page should pass the portfolio test — would you screenshot this for social media?"
polish: "Micro-interactions on every interactive element — hover, focus, active states mandatory"
```

## What happens

1. **Discovery**: design-loop finds your skill via keyword matching
2. **Passive enrichment**: Your scoring criteria enrich the reviewer in all modes
3. **No trigger needed**: Aesthetic skills don't generate code, so `trigger` and `generator` are omitted
4. **Redesign amplifier**: In Redesign mode, your full SKILL.md body is loaded — the more opinionated your guidelines, the richer the creative direction
